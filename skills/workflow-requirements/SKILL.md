# Workflow: Requirements Gathering (Phase 1)

## Purpose

Run the complete SDLC Phase 1 process for a given feature request or system improvement: interview stakeholders, map interests, analyze current processes, and produce a completed PRD or RFD.

## When to Use

Invoke when a business-analyst receives a plain-language request and needs to produce a structured requirement document before design or development begins.

## Quick Reference

| Input | Plain-language feature request or problem statement |
|-------|-----------------------------------------------------|
| Output | Completed PRD (user-facing) or RFD (technical) |
| Agent | `business-analyst` |
| SDLC Phase | Phase 1 — Ideate |

## Summary of Steps

1. Classify the request (user-facing feature → PRD; technical improvement → RFD)
2. Run structured requirements interview
3. Map stakeholders (inline — no separate invocation needed)
4. Analyze current process (inline — no separate invocation needed)
5. Produce and deliver the output document

For full step-by-step detail, read `SKILL-DETAILS.md` in this directory.
