# Requirements Gathering Skill

## Purpose

- Systematically collect, clarify, and document requirements from stakeholders

## Workflow

1. Identify and list all stakeholders
2. Collect initial requirements from each stakeholder
3. Clarify ambiguities and resolve conflicts
4. Summarize requirements in actionable statements
5. Document open questions and unresolved issues
6. Confirm requirements with stakeholders

## Best Practices

- Ask targeted questions to fill gaps
- Use clear, non-technical language
- Reference source documents and stakeholder input
- Keep requirements concise and actionable

## Quick Start

1. Invoke this skill during project initiation or requirements phase
2. Use output to guide planning and implementation
