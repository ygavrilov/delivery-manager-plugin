# Stakeholder Mapping Skill

## Purpose

- Identify stakeholders, their roles, interests, and influence

## Workflow

1. List all stakeholders involved in the project
2. Document each stakeholder's role and interests
3. Assess influence and impact on project decisions
4. Map relationships and communication channels
5. Summarize key stakeholders and their priorities

## Quick Start

1. Invoke this skill at project start or when stakeholder landscape changes
2. Use output to inform communication and decision-making
